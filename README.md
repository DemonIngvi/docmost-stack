# docmost-stack

Запуск Docmost для документации. Docker работает внутри WSL Ubuntu.

1. Скопируйте `.env.example` в `.env` и задайте свои секреты.
2. Запустите `start-docmost.ps1`, откроется <http://localhost:3100>.
3. Остановка: `stop-docmost.ps1`. Данные сохраняются.

После перезагрузки компьютера запускайте скрипт снова: WSL не стартует сам, а без удерживающего процесса гасит виртуальную машину при простое.

База и файлы лежат в томах Docker внутри WSL. Файлы `.env` и `admin-credentials.txt` в репозиторий не входят.
